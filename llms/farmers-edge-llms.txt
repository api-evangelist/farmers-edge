# Farmers Edge — FarmCommand API

> Farmers Edge is a precision-agriculture and digital-farming company. Its FarmCommand platform
> combines satellite imagery, connected weather stations, in-field telematics (the CanPlug IoT
> device), agronomic modeling, carbon-program tooling, and soil/lab products (LabCommand,
> Hefty/FESoils). The public FarmCommand API is a Django REST service authenticated with a
> FarmCommand API token passed as the `token` query parameter.

## APIs
- [FarmCommand API — interactive docs](https://api.farmcommand.com/docs/): Swagger UI for the public FarmCommand API (host admin.farmcommand.com).
- [FarmCommand API — OpenAPI (Swagger 2.0)](https://api.farmcommand.com/docs/?format=openapi): machine-readable spec, 25 operations.
- [FarmCommand API — ReDoc](https://api.farmcommand.com/redoc/): alternate reference rendering.

## Surface
- Self-serve client onboarding: create, verify, resend verification, validate username.
- Token login: FarmCommand, LabCommand, GridCalc, RecEngine, Hefty products.
- Account management: forgot/reset/change password.
- CanPlug: IoT device lookup by IMEI.
- Contacts: unsubscribe / verify by token.
- Inbound webhooks (provider-to-provider): Stripe billing, DocuSign envelopes, LEAF field alerts.
